# 20. Access control

## 1. Overview

Access control must extend beyond static rate-limiting at the API Gateway and simple Role-Based Access Control (RBAC) after login. "Low and slow" credential stuffing botnets increasingly bypass static defenses by rotating IP addresses and spreading out login attempts. To counter this, modern access control uses dynamic Zero Trust architectures to continuously adjust authentication and authorization based on context, location, device fingerprinting, TLS fingerprinting, and real-time behavior. 

Effective access control also requires post-login containment to limit what a client can do after authentication. Risk-adaptive policies limit the blast radius of a successful account takeover by enforcing step-up authentication or restricting sensitive operations during suspicious sessions.

## 2. Thesis Statements

**Thesis Statement 1**
> Static rate-limiting and traditional password authentication cannot stop highly distributed, "low-and-slow" credential stuffing botnets. The API Gateway requires dynamic, context-aware authentication rules.

**Thesis Statement 2**
> A risk-adaptive access-control model that incorporates login-session risk, derived from device, TLS, and behavioral signals, limits account-takeover impact more effectively than static Role-Based Access Control (RBAC).

## 3. Literature Review

**Literature Review supporting Thesis Statement 1**

Recent research introduces frameworks for adaptive detection within Zero Trust architectures to replace static rate-limiting with context-aware authentication.[^1][^2]

*   **Title:** *Identity Threat Detection: Techniques for Preventing Credential Abuse in Cloud Systems*
*   **Authors:** Lalith Sriram Datla
*   **Methodology and Findings:** This study introduces frameworks that use signal correlation, identity-focused risk evaluation, and telemetry to identify credential-based assaults. Contextual analysis at the gateway helps detect distributed bots mimicking legitimate users.
*   **Link:** https://ijetcsit.org/index.php/ijetcsit/article/view/498/
* [Link to Article](/20.3/1.1/IJETCSIT-V2I4P111.pdf)

*   **Title:** *Blockchain-Infused Zero Trust: Enhancing Adaptive Authentication and Access Control in Mobile Banking*
*   **Authors:** Parthiban S, Dr R Raja Guru, Ramana M, Harihara Priyan KS, B Prem Kumar
*   **Methodology and Findings:** This research proposes models for mobile banking that continuously evaluate user behavior and device characteristics to assign risk scores to authentication attempts.
*   **Link:** https://www.techrxiv.org/doi/full/10.36227/techrxiv.175427164.43750668/v1
* [Link to Article](/20.3/1.2/techrxiv.175427164.43750668_v1.pdf)

**Literature Review supporting Thesis Statement 2**

Research on Risk-Based Authentication shows how context-aware security mechanisms handle post-login security and limit account-takeover impact.[^3]

*   **Title:** *Utilization of Risk-Based Authentication in Cloud Identity Services*
*   **Authors:** Deepthi Talasila
*   **Methodology and Findings:** This paper applies context-aware security mechanisms that use real-time data on behavior and location. Continuously evaluating a session's risk score restricts the permissions of compromised accounts and contains credential stuffing better than static RBAC.
*   **Link:** https://www.digitalsecurityforensics.org/digisecforensics/article/view/89
* [Link to Article](/20.3/2.1/171570d069ee911779f61cfdd6b48632fac8.pdf)
