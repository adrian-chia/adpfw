# 20. Access control

## 1. Overview

Access control in modern application security must extend beyond traditional static rate-limiting at the API Gateway and simple Role-Based Access Control (RBAC) post-login. "Low and slow" credential stuffing botnets increasingly bypass static defenses by rotating IP addresses and executing infrequent, distributed login attempts. To counter this, modern access control requires AI-driven, dynamic Zero Trust architectures that continuously adjust authentication and authorization based on context, location, device and TLS fingerprinting, and real-time behavior. Furthermore, effective access control involves post-login containment—using risk-adaptive policies to restrict what a client can do after authentication. This limits the blast radius of any successful account takeover by enforcing step-up authentication or restricting sensitive operations for suspicious sessions.

## 2. Thesis Statements

**Thesis Statement 1**
> Static rate-limiting and traditional password authentication are fundamentally inadequate; implementing AI-driven, dynamic, context-aware authentication rules at the API Gateway is essential to intercept highly distributed, "low-and-slow" credential stuffing botnets.

**Thesis Statement 2**
> A risk-adaptive access-control model that incorporates login-session risk—derived from device, TLS, and behavioral signals—limits account-takeover impact more effectively than static Role-Based Access Control (RBAC).

## 3. Literature Review

**Literature Review supporting Thesis Statement 1**

To support the assertion that static rate-limiting is inadequate and dynamic, context-aware authentication is essential, recent research introduces frameworks for adaptive detection within Zero Trust architectures.[^1][^2]

*   **Title:** *Identity Threat Detection: Techniques for Preventing Credential Abuse in Cloud Systems*
*   **Authors:** Lalith Sriram Datla
*   **Methodology and Findings:** The study introduces frameworks that use signal correlation, identity-focused risk evaluation, and telemetry to identify credential-based assaults. The findings demonstrate that contextual analysis at the gateway is necessary to detect distributed bots mimicking legitimate users.
*   **Link:** https://ijetcsit.org/index.php/ijetcsit/article/view/498/
* [Link to Article](/20.3/1.1/IJETCSIT-V2I4P111.pdf)

*   **Title:** *Blockchain-Infused Zero Trust: Enhancing Adaptive Authentication and Access Control in Mobile Banking*
*   **Authors:** Parthiban S, Dr R Raja Guru, Ramana M, Harihara Priyan KS, B Prem Kumar
*   **Methodology and Findings:** This research proposes enhanced models for mobile banking that emphasize the continuous evaluation of user behavior and device characteristics to assign dynamic risk scores to authentication attempts. This reinforces the need for dynamic authentication over static thresholds.
*   **Link:** https://www.techrxiv.org/doi/full/10.36227/techrxiv.175427164.43750668/v1
* [Link to Article](/20.3/1.2/techrxiv.175427164.43750668_v1.pdf)

**Literature Review supporting Thesis Statement 2**

Addressing the challenge of post-login security and the mitigation of account-takeover impact, the utilization of Risk-Based Authentication provides critical evidence.[^3]

*   **Title:** *Utilization of Risk-Based Authentication in Cloud Identity Services*
*   **Authors:** Deepthi Talasila
*   **Methodology and Findings:** This paper explores applying context-aware security mechanisms that leverage real-time data on behavior and location. The methodology demonstrates that continuously evaluating a session's risk score restricts the permissions of compromised accounts and contains the potential damage of credential stuffing more effectively than static RBAC.
*   **Link:** https://www.digitalsecurityforensics.org/digisecforensics/article/view/89
* [Link to Article](/20.3/2.1/171570d069ee911779f61cfdd6b48632fac8.pdf)
