# 19. Web Security

## 1. Overview
In the context of the modern Open Banking API ecosystem, web security revolves around protecting the HTTP/HTTPS interfaces that allow Third-Party Providers (TPPs) to access sensitive financial data. Traditional web security controls—such as standard firewalls, web application firewalls (WAFs), and basic rate limiting—operate primarily at the request level. These perimeter defenses struggle to interpret the complex, stateful authorization logic passed between clients and services. 

Consequently, Open Banking networks remain highly vulnerable to logic-based API flaws, such as:
- Broken Object Level Authorization (BOLA) and object-ID manipulation.
- Automated credential stuffing and token theft.
- Large-scale data scraping and exfiltration.
- Unsafe consumption of APIs by compromised third parties.

To secure high-value business objects, modern web security architectures must evolve from static rules to behavior-aware, real-time anomaly detection capable of understanding data-flow semantics.

## 2. Thesis Statements

**Thesis Statement 1: Integration of GNNs**
> Integrating Graph Neural Networks (GNNs) into API gateway security layers provides a scalable and behavior-aware mechanism to identify and block logic-based vulnerabilities like Broken Object Level Authorization (BOLA) without relying on outdated signature-based firewall rules.

**Thesis Statement 2: Defense-in-Depth Architecture**
> A defense-in-depth Open Banking web-security architecture combining Financial-Grade API (FAPI) protocol compliance with real-time streaming telemetry analysis reduces exposure to automated credential stuffing and large-scale data exfiltration more effectively than static perimeter controls alone.

## 3. Literature Review

The shift toward Open Banking has driven a massive increase in API traffic, necessitating dynamic, self-adapting security systems. Traditional tabular anomaly detection or perimeter-driven architectures often fail to capture the complex authorization flaws inherent in financial API abuse.

### Broken Object Level Authorization (BOLA) and Logic Flaws
BOLA operates as a critical authorization flaw that bypasses traditional authentication. By highlighting the limitations of request-local validation in detecting object ID manipulation, research reinforces the necessity for advanced API gateway logic to mitigate logic-based attacks.
* **Supports Thesis 1 (Integration of GNNs):** Establishes the critical limitation of perimeter firewalls when it comes to stateful logic flaws, providing the motivation for graph-based anomaly detection.
* **Relevant Literature:** *Broken Object Level Authorization* details how BOLA operates as a critical authorization flaw that bypasses traditional authentication.
* [Link to Article](https://doi.org/10.1007/979-8-8688-2391-6_3)

### Graph Neural Networks for Security
GNNs have emerged as a superior approach for identifying malicious anomalies within complex, structured networks, providing a methodological foundation for baselining expected API behavior.
* **Supports Thesis 1 (Integration of GNNs):** Provides the methodological foundation for utilizing GNNs to baseline expected API behavior and detect subtle deviations indicative of sophisticated BOLA exploitation.
* **Relevant Literature:** *Graph Neural Networks in Anomaly Detection* explores the application of GNNs in identifying malicious anomalies within complex, structured networks.
* [Link to Article](https://doi.org/10.1007/978-981-16-6054-2_26)

### Defense-in-Depth and Open Banking Ecosystems
Focusing specifically on the financial sector, research evaluates the vulnerabilities inherent in Open Banking networks, demonstrating that strict adherence to baseline protocols (like FAPI) is insufficient on its own without continuous telemetry.
* **Supports Thesis 2 (Defense-in-Depth Architecture):** Strongly advocates for continuous monitoring and streaming analytics combined with strict protocol compliance to prevent unauthorized data exfiltration.
* **Relevant Literature:** *API Vulnerability Detection in Open Banking Ecosystems* demonstrates that strict adherence to baseline protocols is insufficient and advocates for continuous monitoring.
* [Link to Article](https://doi.org/10.2139/ssrn.6955398)
