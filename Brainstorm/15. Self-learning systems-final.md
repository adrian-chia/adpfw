# 15. Self-learning systems

## 1. Overview

In the context of modern cybersecurity, self-learning systems refer to autonomous machine learning algorithms designed to continuously update their behavioral baselines to detect stealthy threats like low-and-slow credential stuffing. Malicious actors increasingly deploy highly distributed, AI-driven botnets that rotate through thousands of IP addresses, making login attempts at a rate as low as one per minute per IP. Because traditional rate-limiting at the API Gateway relies on static rules (e.g., blocking an IP if requests exceed a certain threshold), it completely misses these subtle attacks. To counter this, an adaptive learning system ingests and analyzes diverse streaming telemetry—such as request headers, IP reputation, TLS fingerprints (like JA3/JA4), device context, and authentication failure patterns. By analyzing this data dynamically and aggregating it at the campaign level, the system establishes evolving baselines of normal human interactions. This enables administrators to construct a smarter, adaptive API Gateway throttling algorithm capable of accurately isolating and neutralizing zero-day anomalies and highly distributed botnets before extensive credential theft occurs.

## 2. Thesis Statements

**Thesis Statement 1**
> Implementing self-learning systems within cloud-native API Gateways enables the continuous analysis of TLS and device fingerprints, accurately isolating and neutralizing low-and-slow credential stuffing attacks that evade static security rules.

**Thesis Statement 2**
> By continuously updating behavioral baselines, reinforcement-learning-based adaptive API throttling can dynamically adjust access controls in real-time, preventing AI-driven botnets from testing stolen credentials without impacting the legitimate user experience.

## 3. Literature Review

**Literature Review supporting Thesis Statement 1**

To support the assertion that analyzing TLS fingerprints accurately isolates low-and-slow attacks, recent research on multi-layer fingerprinting provides critical evidence.[^1] 

*   **Title:** *When Handshakes Tell the Truth: Detecting Web Bad Bots via TLS Fingerprints*
*   **Authors:** Ghalia Jarad, Kemal Bicakci
*   **Methodology and Findings:** The researchers evaluated the efficacy of protocol-level TLS fingerprinting (JA4) to distinguish bots from human users. By training machine learning classifiers (XGBoost and CatBoost) on the JA4DB dataset, their methodology demonstrated that because automated tools utilize different underlying libraries than standard browsers, their TLS `ClientHello` signatures remain distinctly identifiable. The study found that this approach achieves extremely high accuracy (AUC 0.998) in bot detection, proving that TLS fingerprinting successfully identifies credential stuffing scripts even when attackers rotate IP addresses or spoof `User-Agent` strings.
*   **Link:** https://arxiv.org/abs/2602.09606
* [Link to Article](/15.3/1.1/2602.09606v1.pdf)

**Literature Review supporting Thesis Statement 2**

To support the assertion that self-learning algorithms can dynamically adjust API throttling, modern frameworks utilizing reinforcement learning (RL) offer substantial validation.[^2][^3]

*   **Title:** *Multi-Objective Adaptive Rate Limiting in Microservices Using Deep Reinforcement Learning*
*   **Authors:** Ning Lyu, Yuxi Wang, Ziyu Cheng, Qingyuan Zhang, Feng Chen
*   **Methodology and Findings:** The authors proposed a deep RL strategy utilizing DQN and A3C algorithms to dynamically adjust rate limits based on system load and traffic patterns. Their methodology replaced fixed static thresholds with an adaptive system that learns from continuous environmental feedback. The findings reported significant improvements in throughput and a reduction in latency, proving that adaptive models can mitigate abuse while maintaining system stability and legitimate user access.
*   **Link:** https://arxiv.org/abs/2511.03279
* [Link to Article](/15.3/2.1/2511.03279v1.pdf)

*   **Title:** *Designing CAPTCHA Systems with Reinforcement Learning for Adaptive Defense*
*   **Authors:** Meghana Indukuri, Eman Naseerkhan, Joshua Rose, Martin Tran, Younghee Park
*   **Methodology and Findings:** This paper modeled bot detection as a Partially Observable Markov Decision Process (POMDP) and utilized a PPO+LSTM agent to adaptively calibrate security challenges. The methodology involved dynamically triggering CAPTCHAs based on real-time classification confidence rather than static volumetric triggers. The findings demonstrated that this adaptive defense mechanism accurately addresses sophisticated bot threats like credential stuffing by applying friction only when malicious intent is highly probable, thereby avoiding negative impacts on legitimate users.
*   **Link:** https://www.mdpi.com/2079-9292/15/11/2363
* [Link to Article](/15.3/2.2/electronics-15-02363.pdf)
