# 19. Web security

## 1. Overview

To secure web API login endpoints against distributed botnets, administrators must move beyond static signatures. Instead of high-volume attacks that trigger immediate alarms, attackers now use “low and slow” credential stuffing campaigns. These bots rotate through thousands of IP addresses, making infrequent authentication attempts, such as one per minute, that bypass traditional rate limiting. An effective defense requires an API Gateway that uses machine learning. This approach analyzes device continuity, TLS fingerprints, and application-layer behavior to separate legitimate users from botnets.

## 2. Thesis Statements

**Thesis Statement 1**
> Securing API login endpoints requires replacing static firewalls with machine learning models that can identify and block low-frequency botnets.

**Thesis Statement 2**
> Combining TLS fingerprinting and request-header analysis at the API Gateway provides an accurate defense against low-and-slow credential stuffing attacks.

## 3. Literature Review

**Literature Review supporting Thesis Statement 1**

Current literature argues for a transition from rigid, rule-based edge defenses to adaptive security frameworks.[^1]

*   **Title:** *Machine Learning for Securing API Gateways: A Systematic Literature Review*
*   **Authors:** B. Junedi Hutagaol, Riama Santy Sitorus, Dita Madonna Simanjuntak
*   **Methodology and Findings:** Embedding machine learning models directly into API gateways allows for real-time anomaly detection. These systems establish behavioral baselines to distinguish legitimate human traffic from low-rate credential stuffing that evades traditional volume-based rate limiting.
*   **Link:** https://www.researchgate.net/publication/395047921_Machine_Learning_for_Securing_API_Gateways_a_Systematic_Literature_Review
* [Link to Article](/19.3/1.1/Machine_Learning_for_Securing_API_Gateways_a_Syste.pdf)

**Literature Review supporting Thesis Statement 2**

Research into cryptographic fingerprinting shows it can identify automated traffic regardless of IP address rotation.[^2]

*   **Title:** *When Handshakes Tell the Truth: Detecting Web Bad Bots via TLS Fingerprints*
*   **Authors:** Ghalia Jarad, Kemal Bicakci
*   **Methodology and Findings:** Combining JA4 and JA3 TLS fingerprinting with gradient-boosted classifiers like XGBoost accurately detects evasive bots. Analyzing low-level TLS handshake parameters allows administrators to trace distributed attacks back to their originating botnet families.
*   **Link:** https://arxiv.org/abs/2602.09606
* [Link to Article](/19.3/2.1/2602.09606v1.pdf)

**Literature Review supporting Thesis Statement 1 & 2**

Integrating explainable AI (XAI) into cloud-native architectures strengthens adaptive API defenses.[^3]

*   **Title:** *AI-Driven Real-Time API Security: Explainable Threat Detection for Cloud Environments*
*   **Authors:** Akshay Mittal, Pragya Keshap, Arpana Hosabettu
*   **Methodology and Findings:** Combining anomaly detection (such as Isolation Forests) with interpretability tools (such as SHAP) allows DevOps teams to deploy transparent, low-latency threat mitigation. This approach flags anomalous header and behavioral patterns while minimizing false positives.
*   **Link:** https://www.techrxiv.org/doi/full/10.36227/techrxiv.175695570.09221013/v1
* [Link to Article](/19.3/3.1/techrxiv.175695570.09221013_v1.pdf)
