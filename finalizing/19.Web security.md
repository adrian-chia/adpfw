**1\. Overview**

To secure web API login endpoints against distributed botnets, administrators can no longer rely on static signatures. Attackers now use "low and slow" credential stuffing campaigns instead of high-volume attacks that trigger alarms. These bots rotate through thousands of IP addresses and make infrequent login attempts, sometimes just one per minute, to bypass traditional rate limits. To stop them, an API Gateway needs machine learning to analyze device continuity, TLS fingerprints, and application-layer behavior. This helps distinguish human users from automated attacks.


**2\. Problem Statement**

Standard API Gateway rate limits miss "low and slow" credential stuffing attacks. Attackers use distributed botnets that rotate through thousands of IP addresses, keeping authentication attempts below volume thresholds. This bypasses traditional network defenses. To detect these attacks, administrators must apply data analytics to the telemetry generated at API login endpoints. They can extract temporal patterns and feature sets from timestamps, request headers, TLS fingerprints, and authentication failure rates to distinguish human users from botnets.


**3\. Finalized Thesis Statement**
> "Standard API Gateway rate-limiting fails against highly distributed, 'low-and-slow' credential stuffing botnets. This thesis proposes that training machine learning models on a combination of TLS fingerprints and request headers provides an adaptive defense that can stop low-frequency authentication attacks."


**4\. Preliminary Literature Review**

The following peer-reviewed literature provides the academic foundation for this research direction:

* **Machine Learning for Securing API Gateways: A Systematic Literature Review** (Hutagaol, Sitorus, Simanjuntak): This research argues for moving from static edge defenses to adaptive frameworks. It demonstrates that embedding machine learning models into API gateways allows for real-time anomaly detection. This establishes the behavioral baselines needed to distinguish human traffic from low-rate credential stuffing that evades volume-based rate limits.

* **When Handshakes Tell the Truth: Detecting Web Bad Bots via TLS Fingerprints** (Jarad, Bicakci): This study shows that cryptographic fingerprinting identifies automated traffic regardless of IP address rotation. The authors found that combining JA4 and JA3 TLS fingerprinting with gradient-boosted classifiers, such as XGBoost, detects evasive bots. Analyzing these TLS handshake parameters allows administrators to trace distributed attacks back to their botnet families.

* **AI-Driven Real-Time API Security: Explainable Threat Detection for Cloud Environments** (Mittal, Keshap, Hosabettu): This paper focuses on integrating explainable AI into cloud-native architectures. By combining anomaly detection models like Isolation Forests with interpretability tools like SHAP, security teams can deploy transparent, low-latency defenses. This approach flags anomalous header and behavioral patterns while minimizing false positives.
