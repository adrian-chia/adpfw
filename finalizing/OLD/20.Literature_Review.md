## 2. Brief Literature Review Section

Security teams are moving away from rigid edge defenses because rule-based rate limits fail against modern botnets. Attackers now limit their request rates to mimic human behavior. To detect these low-rate credential stuffing attacks, API gateways can use machine learning to analyze traffic and establish behavioral baselines in real time.[^1][^2]

Cryptographic fingerprinting reliably identifies automated traffic even when attackers rotate IP addresses.[^3] By analyzing TLS handshake parameters (like JA3 and JA4 fingerprints) with gradient-boosted classifiers such as XGBoost, systems can detect evasive bots.[^4] As Althouse explains, «The TLS handshake is one of the few unencrypted elements in modern web traffic, making it a reliable indicator of client intent.»[^5]

Defensive models in production need to be transparent. Cloud-native architectures can pair anomaly detection algorithms, such as Isolation Forests, with interpretability tools like SHAP.[^6] This combination flags unusual header patterns, keeps false positives low, and shows administrators exactly why the system blocked an attack.[^7]
